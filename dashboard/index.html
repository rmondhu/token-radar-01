How the ranking works

Implied value = TVL × category multiple. The multiple is the median mcap/TVL of token-bearing protocols in the same category (128 comparables with a positive circulating mcap). Categories with fewer than 5 comparables use the fallback multiple 0.082 — the median of the 52 comparables with TVL ≥ $50M. The score then adjusts for 7-day TVL momentum (clamped −50%…+100%) and chain breadth (up to +20% for 10+ chains). Implied value is a circulating market cap, never FDV — the snapshot has no supply data.

What the board is: the 40-protocol watchlist taken verbatim from the snapshot (it cannot be recomputed — 20 child products are excluded only via data not in the file), plus the next 60 no-token protocols below the $50M floor by TVL. A protocol being here is not a claim it will launch a token — the snapshot contains no launch signal at all. Several rows are vault/curator businesses, stablecoins, chains or networks that may never issue a token.

Farm plans are category-generic (chains + action family + age/TVL/momentum context). Points status is unverified for every row — the snapshot never says whether a protocol has a points program. Protocol links use DefiLlama's public URL pattern (defillama.com/protocol/<slug>), constructed, not from the snapshot.
